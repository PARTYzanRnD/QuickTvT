# Plan: Defend Faction Restriction for Previous Defenders

## Summary
When game state transitions to GAME, players on `GetDefendFaction()` get a "flag" (playerId stored in a replicated array). When SLOTSELECTION starts, flagged players cannot select DefendFaction roles for 1 minute. Timer uses existing `m_iStepTime`. Chat message "Уже играли за оборону - низкий приоритет" shown client-side in `QTvT_M_CharacterSelector.c` via `lmsg` invoker, mimicking the balance message flow.

## Files to Modify

### 1. `QuickTvT/scripts/game/PS_GameModeQuickTvT.c`

**New member variables:**
```c
[RplProp()]
protected ref array<int> m_aDefendFlagPlayerIds = {};

int m_iLastCanJoinFactionPlayerId = -1;
```
- `m_aDefendFlagPlayerIds` — replicated array of playerIds who were on defend faction during GAME. Synced to clients for the UI check.
- `m_iLastCanJoinFactionPlayerId` — transient server-only int, set by RPC callers before `CanJoinFaction`.

**Modify `OnGameStateChanged()`:**

In `case SCR_EGameModeState.GAME:` — flag current defend faction players:
```c
m_aDefendFlagPlayerIds.Clear();
GUB_RandomizeSpawnManager spawnManager = GetRandomizeSpawnManager();
if (spawnManager && spawnManager.GetDefendFaction())
{
    FactionKey defendFactionKey = spawnManager.GetDefendFaction().m_sFactionKey;
    array<int> playerIds = {};
    m_PlayerManager.GetPlayers(playerIds);
    foreach (int pId : playerIds)
    {
        if (m_playableManager.GetPlayerFactionKey(pId) == defendFactionKey)
            m_aDefendFlagPlayerIds.Insert(pId);
    }
}
Replication.BumpMe();
```

**New method `IsDefendFactionRestricted`:**
Uses existing `m_iStepTime` for timer. `m_iSlotsTime - m_iStepTime` = elapsed time in SLOTSELECTION. If >= 60000ms, restriction lifts. Works on both server and client — server uses `m_mDefendFlagPlayers` (private), client uses `m_aDefendFlagPlayerIds` (replicated).

Actually — simpler: just use `m_aDefendFlagPlayerIds` everywhere (both server and client). Remove the separate `m_mDefendFlagPlayers` map entirely.

```c
bool IsDefendFactionRestricted(int playerId, FactionKey factionKeyPlayer)
{
    if (GetState() != SCR_EGameModeState.SLOTSELECTION)
        return false;
    if (!m_aDefendFlagPlayerIds.Contains(playerId))
        return false;
    GUB_RandomizeSpawnManager spawnManager = GetRandomizeSpawnManager();
    if (!spawnManager || !spawnManager.GetDefendFaction())
        return false;
    if (factionKeyPlayer != spawnManager.GetDefendFaction().m_sFactionKey)
        return false;
    int elapsed = m_iSlotsTime - m_iStepTime;
    if (elapsed >= 60000)
        return false;
    return true;
}
```

**In `CanJoinFaction()` override** — add at beginning, before existing balance logic:
```c
if (m_iLastCanJoinFactionPlayerId >= 0 && IsDefendFactionRestricted(m_iLastCanJoinFactionPlayerId, factionKeyPlayer))
    return false;
m_iLastCanJoinFactionPlayerId = -1;
```
Then continue with existing balance logic unchanged.

### 2. `QuickTvT/scripts/game/lib/QTvT_M_CharacterSelector.c`

**Modify `CanJoinFaction()` method** — add defend restriction check before the existing `gameModeCoop.CanJoinFaction()` call. Mimics the balance message pattern:

```c
bool CanJoinFaction()
{
    PS_GameModeCoop gameModeCoop = PS_GameModeCoop.Cast(GetGame().GetGameMode());
    PS_GameModeQuickTvT gameModeQuickTvT = PS_GameModeQuickTvT.Cast(GetGame().GetGameMode());
    if (m_PlayableContainer)
    {
        if (gameModeQuickTvT && gameModeQuickTvT.IsDefendFactionRestricted(m_iCurrentPlayerId, m_sFactionKey))
        {
            SCR_ChatPanelManager chatPanelManager = SCR_ChatPanelManager.GetInstance();
            ChatCommandInvoker invoker = chatPanelManager.GetCommandInvoker("lmsg");
            invoker.Invoke(null, "Уже играли за оборону - низкий приоритет");
            m_CoopLobby.SetPreviewPlayable(m_iPlayableId, true);
            return false;
        }
        if (gameModeQuickTvT)
            gameModeQuickTvT.m_iLastCanJoinFactionPlayerId = m_iCurrentPlayerId;
        if (!PS_PlayersHelper.IsAdminOrServer() && !gameModeCoop.CanJoinFaction(m_sFactionKey, m_PlayableManager.GetPlayerFactionKey(m_iCurrentPlayerId)))
            return false;
    }
    return true;
}
```

## Design Notes

- **Timer**: Uses existing `m_iStepTime` (`[RplProp()]`, counts down from `m_iSlotsTime`). Elapsed = `m_iSlotsTime - m_iStepTime`. If >= 60000ms, restriction lifts. No extra network sync.
- **Defend flag sync**: `m_aDefendFlagPlayerIds` is `[RplProp()]` so clients can check it in `QTvT_M_CharacterSelector.CanJoinFaction()`. Set once in GAME state `OnGameStateChanged`, then `Replication.BumpMe()`.
- **Chat message**: "Уже играли за оборону - низкий приоритет" via `lmsg` invoker, mimicking the balance message flow entirely on the client side.
- **Server enforcement**: `CanJoinFaction` override in `PS_GameModeQuickTvT` with `m_iLastCanJoinFactionPlayerId` set by modded RPC handlers.
- **No admin bypass** (user confirmed).
- **Flag at GAME start** (user confirmed).
- **`GetRandomizeSpawnManager()`**: Global singleton from `Lobby_Missions_Modules_AR` mod, available on both client and server.
