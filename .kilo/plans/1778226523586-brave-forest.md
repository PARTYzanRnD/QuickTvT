# Plan: Restrict FreeSlot action for defend-faction slots when player is defend-flagged

## Problem
When a defend-flagged player right-clicks a slot that belongs to the defend faction (`m_sFactionKey == m_sFlaggedDefendFactionKey`), the "FreeSlot" context menu action should be hidden/restricted — the same way OnClicked already blocks them from joining.

Currently in `QTvT_M_CharacterSelector.c:162`:
```c
if (m_bCanKick && m_iPlayerId >= 0 && m_iPlayerId != m_iCurrentPlayerId && !localPc.m_bIsDefendFlagged)
    contextMenu.ActionFreeSlot(m_iPlayableId).Insert(OnActionFreeSlot);
```
This hides FreeSlot for ALL flagged players regardless of slot faction. It should only hide it when the slot belongs to the defend faction (`m_sFactionKey == m_sFlaggedDefendFactionKey`).

## Files to Modify

### 1. `scripts/game/lib/QTvT_M_CharacterSelector.c` (line 162)

**Current code:**
```c
if (m_bCanKick && m_iPlayerId >= 0 && m_iPlayerId != m_iCurrentPlayerId && !localPc.m_bIsDefendFlagged)
    contextMenu.ActionFreeSlot(m_iPlayableId).Insert(OnActionFreeSlot);
```

**New code:**
```c
if (m_bCanKick && m_iPlayerId >= 0 && m_iPlayerId != m_iCurrentPlayerId && !(localPc.m_bIsDefendFlagged && m_sFactionKey == localPc.m_sFlaggedDefendFactionKey))
    contextMenu.ActionFreeSlot(m_iPlayableId).Insert(OnActionFreeSlot);
```

**Logic:** FreeSlot is hidden only when BOTH conditions are true:
1. `localPc.m_bIsDefendFlagged` — the local player was flagged for defend last round
2. `m_sFactionKey == localPc.m_sFlaggedDefendFactionKey` — the slot belongs to the faction the player was flagged for

If the slot is on a different faction (e.g., attack), FreeSlot remains available even for flagged players. This also means non-flagged players always see FreeSlot regardless of slot faction.

**Timer:** No 1-minute timer check for FreeSlot — restriction applies for the entire SLOTSELECTION phase (unlike OnClicked which lifts after 60s).

- `QTvT_M_PlayableControllerComponent.c` — already has `m_bIsDefendFlagged` and `m_sFlaggedDefendFactionKey`, no changes needed
- `PS_GameModeQuickTvT.c` — already sends both values via RPC, no changes needed
